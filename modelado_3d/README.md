# Modelado 3D

El ZIP recibido contiene 14 STL (P01 a P14), todos con estructura binaria de longitud consistente, y 2 archivos 3MF (P01 y P07) cuya integridad ZIP se comprobó. La fotografía documenta el marco ensamblado. Esta revisión no certifica tolerancias ni imprimibilidad.

| Piezas | Función |
|---|---|
| P01–P06 | Dintel, paredes, tapas y piso para PIR |
| P07–P08 | Columna derecha para ToF y tapa |
| P09–P10 | Columna izquierda para servo y tapa |
| P11–P12 | Bases |
| P13–P14 | Adaptador SG90 y brazo |

Rutas de carga: STL/ y 3MF/. Se mantienen las piezas originales, con nombre P03 normalizado para evitar doble extensión. Configuración reportada: Bambu Lab A1, PLA, boquilla 0,4 mm, capa 0,2 mm, dos paredes, relleno 15 %.
