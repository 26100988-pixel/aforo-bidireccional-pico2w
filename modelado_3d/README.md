# Modelado 3D

Según el informe (pp. 3–4) y la diapositiva 3, el marco está ensamblado y contiene 14 piezas. Configuración reportada: Bambu Lab A1, PLA, boquilla 0,4 mm, capa 0,2 mm, dos paredes, relleno 15 %.

| Piezas | Función |
|---|---|
| P01–P06 | Dintel, paredes, tapas y piso para PIR |
| P07–P08 | Columna derecha de ToF y tapa |
| P09–P10 | Columna izquierda para servo y tapa |
| P11–P12 | Bases |
| P13–P14 | Adaptador del SG90 y brazo |
